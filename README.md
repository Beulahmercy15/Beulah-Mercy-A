# Beulah Mercy A - Professional Portfolio

[![Live Demo](https://img.shields.io/badge/Live-Demo-success?style=for-the-badge&logo=github)](https://beulahmercy15.github.io/Beulah-Mercy-A/)

Welcome to the personal portfolio website of **Beulah Mercy A**, a motivated and detail-oriented Data Analyst, Business Intelligence Analyst, and Python Developer.

This repository contains the source code for the responsive, modern, and interactive web portfolio, showcasing skills, academic background, projects, and contact information. You can view the live site here: **[Beulah Mercy A Portfolio](https://beulahmercy15.github.io/Beulah-Mercy-A/)**

## 🌟 Features

*   **Modern UI/UX:** Clean design built with HTML, CSS, and Vanilla JavaScript.
*   **Responsive Layout:** Fully optimized for desktops, tablets, and mobile devices.
*   **Dark & Light Mode:** Integrated theme toggler that persists user preference using `localStorage`.
*   **Interactive Animations:** Smooth scrolling, revealing scroll animations using `IntersectionObserver`, and a dynamic typing effect for the hero subtitle.
*   **Live Contact Form:** Integrated with Web3Forms to receive emails directly from the site without the need for a backend.
*   **Project Showcase:** Interactive project cards linking directly to GitHub repositories.

## 🛠️ Technologies Used

*   **HTML5** - Semantic structure and content.
*   **CSS3** - Custom styling, CSS variables for theming, Flexbox/Grid for layout, and modern `clamp()` functions for fluid typography.
*   **JavaScript (Vanilla)** - DOM manipulation, theme handling, scrolling effects, and scrollspy navigation.
*   **Google Fonts** - Uses the *Inter* font family for excellent readability.
*   **Font Awesome** - Scalable vector icons for UI elements and social links.
*   **Web3Forms** - Form submission API.

## 📂 Project Structure

## 💡 How to Run Locally

1. Clone or download this repository to your local machine.
2. Ensure all files (`index.html`, `style.css`, `script.js`, and media assets) are in the same directory.
3. Open `index.html` in any modern web browser (Chrome, Firefox, Edge, Safari) to view the site. No local server or build tools are required!
